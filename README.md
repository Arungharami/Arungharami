## Selected research

| Project | Research question and implementation | Current evidence |
|---|---|---|
| **[Drift-Robust TinyML](https://github.com/Arungharami/Drift-Robust-TinyML-Research-System)** | How do compact electronic-nose models and explanations behave under chronological sensor drift? UCI data, frozen evaluation protocols, XAI, and embedded equivalence checks. | Recorded baseline, drift, and host-side XAI experiments; fused FP32 inference and local-XAI equivalence. Physical MCU latency, memory, and energy validation remain blocked. |
| **[DriftCVE-NLP](https://github.com/Arungharami/DriftCVE-NLP)** | How does vulnerability language change over time, and what happens to CVE classification and retrieval? NVD ingestion, chronological splits, lexical and embedding models, provenance, and result export. | Versioned dataset and recorded experiments with confidence intervals and per-example predictions. Live inference remains pending. |
| **[Biomedical Hybrid IR](https://github.com/Arungharami/biomedical-hybrid-ir)** | When do lexical search, dense retrieval, hybrid fusion, and reranking help biomedical search? TF-IDF, BM25, BGE, MedCPT, reciprocal rank fusion, and cross-encoder evaluation on NFCorpus. | Six evaluated methods, result tables, statistical comparisons, query-level error analysis, and reproducibility documentation. A completed course study with a working manuscript. |
| **[DriftGuard-IoT](https://github.com/Arungharami/DriftGuard-IoT)** | Can leakage-safe intrusion detection remain useful across IoT/IIoT datasets and changing traffic? Baseline reproduction, drift monitoring, adaptation, and resource evaluation. | Development runs and tested evaluation utilities; real-data research campaign remains blocked. Synthetic runs are non-reportable. |
| **[Customer Behavior Prediction — Part 2](https://github.com/Arungharami/Customer-Behavior-Prediction-in-Banking-and-Insurance-2)** | How should financial prediction be evaluated beyond static accuracy? Temporal stability, calibration, explanation stability, and cost-sensitive decisions. | Research protocol, preflight/provenance runner, and evaluation utilities. Empirical manuscript results await benchmark acquisition and execution. |

## How I work

- **Reproducibility:** versioned configurations, explicit data provenance, chronological splits, and saved result artifacts.
- **Honest evaluation:** distinguish measured findings, synthetic demonstrations, pending experiments, and blocked hardware work.
- **Useful explanations:** assess explanation fidelity, stability, and computational cost alongside predictive performance.
- **Reliable delivery:** automated tests, validation gates, documented setup, and clear application boundaries.
